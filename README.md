## 为什么需要这份词库

混元生 3D 是国产最强的图生 3D / 文生 3D 引擎之一，但它的提示词写法和 Stable Diffusion 圈**完全不同**：

- ❌ negative prompt、4k、8k、masterpiece、best quality —— **混元不吃这套**，官方文档明说不需要
- ❌ 多主体一次生成 —— "一只猫和一把椅子"结构必乱
- ✅ 全中文正向描述，50~150 字，写清"是什么、什么颜色、什么材质"

写对了，一次出片；写错了，次次抽卡。

## 五条铁律

1. **一次只描述一个主体**——多主体请分两次生成
2. **全中文正向描述**：写"它是什么、什么颜色、什么材质"，50~150 字最佳
3. **不写生图圈黑话**：negative prompt、4k、8k、masterpiece 一律不写
4. **排除项改成正向说法**：想要"没有底座"→ 写"底部平整、可直接摆放"
5. **面数 / PBR 用工具参数选**，不用写进提示词

## 万能公式

```
{量词,1个}+{主体}，{形状与颜色}，{材质与表面}，{风格}，{姿态或用途，可选}
```

例：`一只深棕色、大眼睛的猫头鹰` ← 官方原例，极简也成立；细节越具体越稳。

## 8 大分类模板（每类 1 填空 + 2 成品）

### ① 手办 / 潮玩（最高频）

**填空**：`一个{人物/动物}的Q版手办，{发型/毛色特征}，穿着{服装}，{表情}，圆润可爱的卡通手办风格，{材质:哑光树脂/光泽陶瓷}质感`

- `一个扎双马尾、穿水手服的少女Q版手办，微笑表情，圆润可爱的卡通风格，哑光树脂质感`
- `一只竖起耳朵的橘猫Q版手办，圆脸大眼，呆萌表情，光滑陶瓷质感，底部平整可直接摆放`

要点：写清"发型/毛色/服装/表情"四件套；"Q版/大头身比例"必带。

### ② 游戏道具 / 资产

**填空**：`一把{类型}，{整体造型}，{材质1}配{材质2}，{颜色}，{风格}风格，造型简洁硬朗`

- `一把双手巨剑，剑身宽厚带凹槽纹路，拉丝金属配暗色皮革缠绕，银灰色，奇幻风格`
- `一瓶圆形玻璃药水，内装蓝色发光液体，软木塞封口，瓶身有气泡纹理，魔幻游戏道具风格`

要点：道具类写"材质对比"（金属+皮革 / 玻璃+液体）最出效果。

### ③ 电商产品

**填空**：`一件{产品}，{外形轮廓}，{主体颜色}，{材质}，{表面处理}，真实摄影风格，细节精致`

- `一台复古便携收音机，圆角方盒造型，奶油白色外壳，金属旋钮与网状扬声器面板，哑光质感，真实摄影风格`
- `一个不锈钢保温杯，细长圆柱形，香槟金色，磨砂表面，杯盖同色，真实摄影风格`

要点："真实摄影风格"必带；写清"表面处理（哑光/高光/拉丝）"。

### ④ 人物角色

**填空**：`一个{身份}的角色，{五官特征}，{发型}，穿着{服装与颜色}，{配饰}，{风格}风格`

- `一位中世纪铁匠，络腮胡，光头，穿着深棕色皮围裙，手臂肌肉粗壮，写实风格`
- `一个太空宇航员，面罩透明可见笑脸，白色宇航服带橙色饰条，胸口有方形控制面板，卡通风格`

要点：按"五官→发型→服装→配饰"顺序写。

### ⑤ 动物生物

**填空**：`一只{动物}，{毛色}，{标志性特征}，{姿态}，{风格}风格`

- `一只圆滚滚的仓鼠，金黄白相间的短毛，两颊鼓起各塞着一颗瓜子，坐姿，写实风格`
- `一条东方祥龙，青金色鳞片，鹿角鹰爪，须发飘逸，盘旋上升姿态，中国风风格`

要点："姿态"词出效果（坐姿/跃起/盘旋）；龙凤类直接挂"中国风"。

### ⑥ 家具家居

**填空**：`一件{家具}，{造型风格}，{框架材质}，{面料与颜色}，{细节工艺}`

- `一把维多利亚风格单人扶手椅，雕花木质框架，深红色绒布软包，滚边工艺，复古做旧质感`
- `一张北欧极简风书桌，浅色橡木桌面板，白色细腿，桌面带隐藏抽屉，现代简约风格`

要点：混元强项（结构规则）；写"框架材质+面料"两段式。

### ⑦ 建筑小景

**填空**：`一座{建筑}，{屋顶/主体特征}，{颜色与材质}，{环境元素，可选}，{风格}`

- `一座日式鸟居，朱红色木柱与黑色屋顶，底部分布两三级石阶，写实风格`
- `一座童话风格糖果屋，姜饼色墙面，白色糖霜屋檐，屋顶铺彩色糖果，卡通风格`

要点：建筑是难点，建议配多视角图走图生 3D；文生仅适合小体量单体（鸟居/亭子/炮塔）。

### ⑧ 文创 / 装饰（预设风格优势区）

**填空**：`一个{器物}，{形制}，{纹样}，{材质釉色}，{风格}风格`

- `一件青花瓷梅瓶，小口短颈丰肩，瓶身绘缠枝莲纹，白底青花釉面，中国风风格`
- `一尊石狮子镇纸，蹲坐姿态，鬃毛卷曲，青灰石材质感，石雕风格`
- `一枚赛博朋克风格的全息徽章，六边形轮廓，中央发光电路纹路，金属边缘，赛博朋克风格`

要点：直接吃混元预设风格词（卡通/中国风/青花瓷/石雕/赛博朋克），命中率最高的一类。

## 好坏对照

| ❌ 差 | 为什么 | ✅ 好 |
|---|---|---|
| `一只猫` | 没有细节，模型自由发挥，十次十个样 | `一只圆滚滚的橘猫,白色四爪,坐姿,短毛,写实风格` |
| `一把剑,8k,masterpiece,最佳质量,超高细节` | 生图黑话无效，挤占描述空间 | `一把双手巨剑,剑身带凹槽纹路,拉丝金属配皮革缠绕,奇幻风格` |
| `一只猫和一把椅子` | 多主体，结构必乱 | 拆两次生成 |

## 图生 3D：好图三要素

1. **单主体**（一个物体占满画面）
2. **背景干净**（纯色背景最佳，杂乱背景会被长成几何）
3. **光线均匀**（避免硬阴影）

真人照片翻车率高？两步法：先用任意 AI 生图把自拍转成 Q 版手办风格，再上传生成 3D。
